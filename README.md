# 列存延迟物化组件

宽表场景下，“先取全行再过滤”会把不需要的列全部读出。本仓库从零实现了一个
列存延迟物化（Late Materialization）组件：先只读筛选列构造候选行号集，过滤完成
后才按行号点取输出列，并提供成本模型在高/低选择性之间自动切换策略。

## 运行方式

```bash
./mvnw -q verify        # 编译 + 全部测试（候选集/延迟物化/多列筛选/随机正确性/策略切换/并发合并/统计）
java -cp target/classes com.example.gsb.columnar.LateMaterializationBenchmark   # 两种策略耗时对比演示
```

## 组件结构（`com.example.gsb.columnar`）

| 类 | 职责 |
|---|---|
| `ColumnStore` | 列存表：每列独立数组；读取按单元计量并可用忙等模拟顺序/随机 IO 成本差异 |
| `ColumnSlice` | 列数据的区间视图（零拷贝），供分片扫描使用 |
| `Filter` / `ColumnPredicate` | 单列过滤条件及常用谓词工厂 |
| `CandidateSet` | 候选集：有序行号 + 过滤阶段已读列值缓存；`scan`/`refine`/`materializeColumn` |
| `Query` / `QueryResult` / `QueryStats` | 查询定义、结果与执行统计快照 |
| `CostModel` | 读取成本模型（与计量口径一致），输出两种策略的估算成本 |
| `QueryPlanner` | 均匀采样估算各过滤条件通过率，按成本模型选择策略 |
| `QueryExecutor` | 单线程执行器：LATE / EARLY / AUTO 三种模式 |
| `ParallelQueryExecutor` | 并发执行器：行号区间分片，各线程独立过滤+物化，按分片顺序合并保持行序 |
| `LateMaterializationBenchmark` | 两种策略的墙钟耗时对比演示 |

## 核心设计

**1. 候选集构造（只读筛选列）**：`CandidateSet.scan` 只对首条筛选列做一次顺序整列
扫描，命中行进入候选集；`refine` 对后续每条过滤条件只在当前候选行上点取求值，
候选集单调收窄。整个过滤阶段不触碰任何输出列。

**2. 延迟物化**：过滤完成后，`materializeColumn` 按最终行号点取输出列；若输出列
恰好是筛选列，则直接复用过滤阶段的缓存值，零额外 IO。

**3. 读取计量口径**：顺序读 1 单元 = 1 单位；按行号点取 1 单元 =
`RANDOM_PENALTY`（10）单位，模拟列存顺序大块 IO 与随机点取的成本差异。

**4. 策略切换条件（成本模型）**：

```
LATE  = N + Σ(i≥2) c(i-1)·R + (O − overlap)·c(k)·R      （c(i) 为第 i 步候选数，R = RANDOM_PENALTY）
EARLY = O·N + (F − overlap)·N                            （O 输出列数，F 筛选列数）
```

单过滤、筛选列与输出列不相交时可化简为：**通过率 p > 1/R（即 10%）时提前物化更划算**
——过滤条件区分度不足、大量行命中时，逐行点取的随机 IO 放大会超过整列顺序读。
`QueryPlanner` 通过均匀采样估算 p，代入成本模型自动决策（`AUTO` 模式）。

## 实测对比（`LateMaterializationBenchmark`，20 万行 × 64 列）

| 场景 | 延迟物化 LATE | 提前物化 EARLY | 规划器选择 |
|---|---|---|---|
| 高选择性 p≈1%，输出 2 列 | **17.4 ms**（读 3/64 列，节省 98.1%） | 39.4 ms | LATE |
| 低选择性 p≈60%，输出 60 列 | 5181.5 ms | **790.9 ms** | EARLY |

## 并发

`ParallelQueryExecutor` 把 `[0, N)` 切成若干连续行号区间，每个线程在各自分片上
独立完成“过滤 → 物化”的完整流水线，最后按分片顺序拼接结果——分片是连续区间，
顺序拼接天然保持原有行序。读取统计通过 `ColumnStore` 的共享原子计数器自动汇总，
与单线程执行的读取量完全一致（有测试断言）。

## 统计（`QueryStats`）

每次执行返回：候选集大小（逐过滤阶段）、物化列数、实际读取列数、整列扫描列数、
顺序/点取读取单元数、被跳过的列数与被跳过的列读取量、全量读取基准值与节省比例。
