## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的列存查询先取全行再过滤，宽表场景下把不需要的列也读了出来。请从零实现一个列存延迟物化组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 数据按列存储，支持构造只包含筛选列的候选集（行号列表）而不取其它列；2) 支持延迟物化：筛选完成后才按行号取所需的输出列，需给出物化列数与全量读取的对比；3) 支持多列组合筛选：多个列条件依次过滤，逐步缩小候选集；4) 正确性：延迟物化结果与直接全列读取再筛选完全一致，需用随机数据验证；5) 支持选择性评估：某列的选择性过低时提前物化可能更划算，需说明切换条件并给出两种策略的耗时对比；6) 支持并发：多线程分别处理行号区间的候选集，结果合并后要保持原有行序；7) 提供统计：候选集大小、物化列数、读取列数与被跳过的列读取量；8) 测试覆盖候选集构造、延迟物化、多列筛选、正确性验证、策略切换与并发合并；`mvn -q verify` 一条命令跑通。
